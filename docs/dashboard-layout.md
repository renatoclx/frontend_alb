# Layout do Dashboard

## Estrutura

```
Dashboard

Cards

Receita últimos 30 dias

Últimas movimentações

Próximas devoluções
```

---

# Cards

Exibir quatro cards na parte superior.

- Receita do mês
- Locações ativas
- Vendas do mês
- Clientes ativos

Todos deverão possuir:

- Ícone
- Título
- Valor principal
- Informação complementar (opcional)

---

# Desktop

Cards em quatro colunas.

O gráfico ocupará toda a largura da página.

A tabela ocupará toda a largura.

A lista de devoluções ficará abaixo da tabela.

---

# Tablet

Cards em duas colunas.

Os demais componentes ocuparão largura total.

---

# Mobile

Todos os componentes empilhados.

Tabela com scroll horizontal quando necessário.

---

# Componentes

Utilizar:

- shadcn/ui
- Recharts
- Lucide React

---

# Aparência

Priorizar:

- Layout limpo.
- Espaçamento consistente.
- Boa hierarquia visual.
- Poucas cores.
- Cards discretos.
- Sombras suaves.
- Bordas arredondadas.

---

# Evitar

Não utilizar:

- gráficos em pizza;
- velocímetros;
- gradientes chamativos;
- excesso de animações;
- excesso de informações.

---

# Consistência

Todos os componentes deverão seguir o Design System existente da aplicação.
