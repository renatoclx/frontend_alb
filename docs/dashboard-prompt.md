# Implementação do Dashboard V1

## Objetivo

Implementar o Dashboard V1 da aplicação seguindo as documentações:

- docs/dashboard.md
- docs/dashboard-layout.md
- docs/dashboard-metrics.md

---

## Antes de implementar

Analise a estrutura atual do projeto e verifique:

- módulos existentes relacionados a vendas e locações;
- padrões utilizados no backend;
- padrões utilizados no frontend;
- componentes já existentes que possam ser reutilizados;
- necessidade de criação de novos endpoints.

Não realize alterações antes de apresentar um plano de implementação.

O plano deverá conter:

- arquivos que serão criados ou alterados;
- possíveis alterações no backend;
- endpoints necessários;
- componentes frontend necessários;
- riscos ou pontos de atenção.

Aguarde aprovação antes de iniciar a implementação.

---

## Regras

- Não criar dados mockados.
- Utilizar dados reais da API.
- Não duplicar regras de negócio existentes.
- Não realizar refatorações fora do escopo.
- Seguir os padrões definidos no projeto.
- Não alterar progress.md ou journal.md sem autorização.

---

## Backend

Caso não existam endpoints necessários para o Dashboard, criar apenas os recursos necessários para disponibilizar as métricas definidas na documentação.

Consultas de agregação devem ser realizadas no backend.

---

## Frontend

Implementar a interface seguindo exatamente os padrões definidos em:

- dashboard-layout.md

Utilizar os componentes e bibliotecas já adotados no projeto.

---

## Finalização

Ao concluir, apresentar:

- arquivos criados;
- arquivos alterados;
- endpoints criados;
- resumo das implementações;
- possíveis melhorias futuras.
